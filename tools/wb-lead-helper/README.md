# WB Lead Helper

Расширение для Яндекс Браузера и Chrome. Сохраняет данные продавца с открытой страницы Wildberries в таблицу: юрлицо или ИП, ИНН, ОГРН, адрес, почту, показатели магазина и фото товара. Таблица выгружается в xlsx.

Страницы расширение не открывает само: вы листаете WB как обычно, а оно копирует данные с той страницы, которая открыта.

## Установка

1. Скачайте архив `wb-lead-helper.zip` и распакуйте его в любую папку.
2. Откройте в браузере `browser://extensions` (в Chrome — `chrome://extensions`).
3. Включите **«Режим разработчика»** (переключатель справа вверху).
4. Нажмите **«Загрузить распакованное расширение»** и выберите распакованную папку `wb-lead-helper`.
5. Откройте wildberries.ru: слева внизу появится тёмная панель **WB Lead Helper**.

## Как пользоваться

**1. Собрать бренды с поиска (по желанию).**
Откройте поиск, например «худи», и нажмите на панели **«Собрать бренды с поиска»**. Расширение запишет уникальные бренды со ссылкой на один товар каждого. Прокрутите ниже и нажмите ещё раз, чтобы добавить следующие.

**2. Сохранить продавца.**
Откройте товар → название продавца → **«Все товары продавца»**. На странице продавца нажмите на панели **«Сохранить продавца»**.
- Расширение само наведёт курсор на значок «i» рядом с названием и прочитает данные.
- Если окно с данными не открылось само, наведите курсор на «i» или нажмите на него: данные сохранятся автоматически.
- Фото первого товара продавца скачается в папку загрузок, в подпапку `wb-leads`.

**Со скриншотом:** нажмите на значок расширения на панели браузера или `Alt+Shift+S`. Скриншот экрана тоже попадёт в папку `wb-leads`.

**3. Выгрузить таблицу.**
На панели нажмите **«Таблица и выгрузка xlsx»** → **«Скачать xlsx»**. В файле три листа: «Продавцы», «Бренды для обхода» и «Шаблон письма».

Если сохранить одного продавца повторно, строка обновится, а не задвоится: повторы отсекаются по ИНН.

## Если что-то не находится

Wildberries часто меняет вёрстку, поэтому расширение ищет данные по тексту («ИНН:», «ОГРН», «товаров продано»), а не по названиям классов. Если какое-то поле перестало заполняться:

1. Откройте страницу продавца с открытым окном «i».
2. Нажмите F12 → вкладка Elements → правой кнопкой по `<html>` → Copy → **Copy outerHTML**.
3. Вставьте результат в файл и пришлите его, расширение поправим под новую вёрстку.

## Данные и правила

- Всё хранится только у вас в браузере (`chrome.storage.local`) и в скачанных файлах. Никуда не отправляется.
- Почты ИП — это персональные данные. Используйте их только для **личного** делового предложения конкретному продавцу и не передавайте третьим лицам.
- Пишите каждому лично, 20–30 писем в день, с фразой для отказа. Тех, кто ответил «нет», удаляйте из базы.
- Не используйте собранную базу для массовой рекламной рассылки: по закону о рекламе это спам, а почтовые сервисы заблокируют ящик.
- Кнопка «Удалить все данные» на странице таблицы полностью очищает базу.

Для выгрузки xlsx используется библиотека SheetJS (лицензия Apache-2.0, файл `lib/SHEETJS-LICENSE`).
