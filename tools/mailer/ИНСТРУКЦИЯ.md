# Рассылка писем селлерам — инструкция для Windows

Программа отправляет **персональные** письма с **одного** вашего ящика: обращается по названию (ИП / ООО), упоминает магазин, вставляет фото работ. Каждому адресу первое письмо уходит только один раз, а напоминание — одно, через 3 дня. Прогрев встроен, поэтому лимит в первые недели маленький.

## Самый простой способ — приложение с кнопками

1. В папке программы дважды щёлкните **«Открыть приложение»**. В браузере откроется окно «Рассылка селлерам».
2. Слева внизу нажмите **«＋ Ярлык на рабочий стол»**. Дальше приложение можно открывать ярлыком с рабочего стола.
3. Пройдите шаги слева по порядку: **Почта → База → Письмо → Проверка → Отправка**. Готовые шаги отмечаются зелёной галочкой.
4. Главный экран показывает, сколько писем можно отправить сегодня, статистику ответов и риск блокировки.
5. Закончили — нажмите **«✕ Закрыть приложение»**. Если просто закрыть вкладку, приложение само выключится через пару минут, но только если не идёт отправка.

Приложение работает только на вашем компьютере: в интернет уходят лишь сами письма. Всё, что описано ниже, оно делает за вас. Файлы .bat оставлены на всякий случай.

## Шаг 1. Установить Python (один раз, 5 минут)

1. Откройте https://www.python.org/downloads/ и нажмите жёлтую кнопку **Download Python**.
2. Запустите скачанный файл.
3. **Обязательно поставьте галочку «Add python.exe to PATH»** внизу первого окна, потом нажмите **Install Now**.
4. В папке программы дважды щёлкните **`1_install.bat`**. Он установит нужную библиотеку.

## Шаг 2. Почта

- Лучше всего подходит **отдельный ящик на Яндексе**, только для работы, не личный. Или ящик на своём домене через Яндекс 360.
- В настройках почты Яндекса включите доступ для программ: **Настройки → Почтовые программы → «С сервера imap.yandex.ru по протоколу IMAP»** и галочку «Пароли приложений и OAuth-токены».

## Шаг 3. Пароль приложения (вместо обычного пароля)

1. Откройте https://id.yandex.ru/security → **Пароли приложений** → **Почта**.
2. Назовите его, например, «Рассылка», и нажмите **Создать**.
3. Скопируйте появившийся пароль. Он показывается один раз.

Для Mail.ru: **Настройки → Безопасность → Пароли для внешних приложений**, а в `config.ini` поставьте `provider = mailru`.

## Шаг 4. Настройки — файл `config.ini`

Откройте его правой кнопкой → «Открыть с помощью» → **Блокнот** и заполните:
- `email` — ваш адрес;
- `app_password` — пароль приложения из шага 3;
- `from_name` и `your_name` — ваше имя;
- `telegram` — ваш ник в Telegram.

Сохраните файл (Ctrl+S).

## Шаг 5. Текст и фото

- **`letter.txt`** — первое письмо, **`followup.txt`** — напоминание. Их можно править в Блокноте. Слова в фигурных скобках программа подставляет сама:
  - `{Компания}` → «ИП Галустов Рафаэль Рудольфович» или «ООО «УЗКОТТОН»»;
  - `{Магазин}` → название магазина на WB;
  - `{Имя}`, `{Telegram}` → из `config.ini`;
  - `{ФОТО}` → место, куда встанут картинки.
- **Папка `photos`** — картинки, которые попадут в письмо, в порядке имён файлов. Лучше 2–3 штуки, не больше 1,5 МБ на все вместе. Можно заменить своими.

## Шаг 6. База

Выгрузите таблицу из расширения WB Lead Helper («Скачать xlsx»). Программа сама найдёт самый свежий файл `wb-leads-*.xlsx` в папке «Загрузки» или рядом с собой.

## Шаг 7. Проверка перед запуском

1. **`2_preview.bat`** — создаёт 5 примеров писем в папке `preview` и ничего не отправляет. Откройте файлы `.eml` двойным щелчком и проверьте текст.
2. **`3_test_to_me.bat`** — отправляет одно письмо **вам самим**. Посмотрите, как оно выглядит в почте и не попало ли в «Спам».

## Шаг 8. Отправка

Каждый рабочий день один раз запускайте **`4_send_today.bat`** и не закрывайте окно, пока программа не напишет «Готово на сегодня».

- Между письмами пауза 1–4 минуты, поэтому 10 писем займут около 20–30 минут.
- Лимит в день: **1-я неделя — 10, 2-я — 20, 3-я — 35, дальше — `max_per_day`** (по умолчанию 50, максимум 100).
- Остановить можно в любой момент: **Ctrl+C**. Всё, что уже отправлено, сохранится.

## Статистика

**`5_report.bat`** показывает:
- сколько писем отправлено;
- сколько человек ответило и сколько сказало «нет»;
- сколько адресов не существует;
- сколько писем уходило по дням;
- **оценку риска блокировки** (низкий / средний / высокий) с объяснением, откуда она взялась.

Запускайте его раз в несколько дней.

## Журнал и ответы

- **`journal.xlsx`** — кому и когда писали и статус каждого адреса. Если файл открыт в Excel во время отправки, программа подождёт, пока вы его закроете.
- Программа сама проверяет входящие: тем, **кто ответил**, напоминание не уходит, а адреса, с которых вернулась ошибка доставки, помечаются «не доставлено».
- **Ответил «нет»** — впишите в `journal.xlsx` в колонку «Статус» слово `отказ` или добавьте адрес в `stoplist.txt`. Больше этому адресу ничего не уйдёт.
- **Отвечайте на ответы сами**, из обычной почты. Ответы — это и есть ваши клиенты.

## Если почта начала отказывать

Программа сама остановится и напишет, что сервер не принимает письма. В этом случае:
1. Не запускайте отправку до завтра.
2. Уменьшите `max_per_day` в `config.ini`.
3. Проверьте текст письма: меньше картинок, без «кричащих» слов.
4. Посмотрите статистику в Яндекс Постмастере.

**Не заводите новые ящики**: почта связывает их между собой, и блокировки распространятся на все.

## Правила, чтобы не попасть в спам

- Пишите только тем, у кого действительно слабые фото: тогда письмо для получателя полезное.
- Не убирайте из письма строку «Если неинтересно — ответьте «нет»».
- Не отправляйте одним днём больше лимита.
